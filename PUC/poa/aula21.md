### O Problema de ontem
- Um aluno explica no quadro um algoritmo para determinar a quantidade mínima de passos para alcançar o objetivo com passos incrementais.
	- O que ele faz foi mostrar a execução do algoritmo dele com árvores.
	- Foi especificado que ele é de busca por profundidade, enquanto o algoritmo especulado ontem foi descrito como largura.
- Qual o pior caso para alcançar o objetivo $n$?
	- O algoritmo do outro Eduardo?
	- Passa do objetivo $n$, dá um pulo a mais pra frente (erra um pouquinho mais propositalmente) e fica andando alterando de frente e pra trás até alcançar $n$.
- JB comenta que puderíamos fazer a execução desse algoritmo do eduardo e alimentá-lo para o algoritmo do Iunis para verificar se conseguirmos encontrar uma solução menor/melhores.
	- Usa o barato fácil rapidão para economizar o mais caro.
