# Respostas das atividades de revisão P1.
## [27-04-2026][mvfm]
---
1. Definição de Processo.
	 Resposta correta : **Alternativa C**
	 "*Um programa em execução, uma entidade ativa com um contador de programa e um conjunto de recursos associados.*"

2. O que ocorre quando um processo é **dispatched**
	 Resposta correta : **Alternativa A**
	 "*Ele muda de estado de Ready para Running.*"

3. O que se é compatilhado entre todas threads.
	 Resposta correta : **Alternativa D**
	 "*Seção de dados, seção de código e recursos do sistema operacional, como arquivos abertos.*"

4. Vantagem de Threads sob Processos.
	 Resposta correta : **Alternativa B**
	 "*A criação de threads é mais econômica em termos de tempo e recursos, pois elas compartilham o espaço de endereçamento do processo pai.*"

5. A IPC que exige que os processos concordem em remover a restrição de acesso múto à memória do Kernel é chamado de :
	Resposta correta : **Alternativa B**
	"*Shared Memory*"

6. Na comunicação por passagem de mensagens, uma operação é considerada "bloqueante" (síncrona) quando : 
	Resposta correta : **Alternativa C**
	"*O processo de envio é bloqueado até que a mensagem seja recebida pelo processo receptor ou pela caixa de correio.*"

7. O termo Dispatch Latency refere-se ao : 
	Resposta correta : **Alternativa B**
	"*Tempo necessário para o despachante parar um processo e iniciar a execução de outro.*"

8. Qual algoritmo de escalonamento da CPU é provadamente ótimo em relação à minimização do tempo de espero médio para um conjunto fixo de processos : 
	Resposta correta : **Alternativa C**
	"*Shortest-Job-First (SJF)*"

9. Race condition ocorre quando :
	Resposta correta : **Alternativa B**
	"*Vários processos acessam e manipulam os mesmos dados concorrentemente, e o resultado da execução depende da ordem específica dos acessos.*"

10. Para que uma solução ao problema da seção crítica seja considerada correta, ela deve satisfazer três requisitos fundamentais :
	Resposta correta : **Alternativa C**
	"*Atomicidade, Durabilidade & Isolamento.*"

11. Um semáforo de contagem é utilizado principalmente para : 
	Resposta correta : **Alternativa A**
	"*Garantir que apenas um processo entre na seção crítica por vez.*"

12. Ocorre um Deadlock quando : 
	Resposta correta : **Alternativa B**
	"*Dois ou mais processos estão esperando indefinidamente por um evento que só pode ser causado por um dos outros processos em espera.*"

13. Quais são as quatro condições necessárias para que ocorra uma situação de Deadlock :

14. Banker's Algorithm é uma estratégia utilizada para :
	Resposta correta : **Alternativa A**
	"*Prevenção de Deadlock*"

15. No contexto de redes & IPC, um *socket* é definido como :
	Resposta correta : **Alternativa B**
	"*Um ponto de extremidade para comunicação, identificado pela concatenação de um endereço IP & um número de porta.*"
