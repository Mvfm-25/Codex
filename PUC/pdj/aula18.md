### Tilesets
- Aula bem barebones hoje, sor aproveitou que veio pouca porcentagem da turma para fazer uma aulinha menor.
- Seguindo essa aula, temos apenas as aulas de acomponhamento de desenvolvimento do T2.
	- Vai ser mais ou menos como apresentação de nosso alpha.
	- Ainda tenho que começar com a secção do jogador, mas a geração de mundo está quase pronta
- Cohen nos apresenta alguns dos fundamentos de uso de Tilemaps.
	- Que é essencialmente a mesma aula de sprites que tivemos algumas aulas atrás.
	- Tilemaps parecem ajudar mais por serem tão modulares, é uma texturona gigante que tem todas as outras texturas que vamos usar no jogo.
- O que é basicamente o que eu queria.
	- Posso fazer algo como um tileset gigante para itens, outro para inimigos, outro para as classes do jogador etc. 
	- Assim como os sprites, Godot tem uma ferramentinha específica para a edição dos tilesets,
- Disponibilizados alguns tutoriais no moodle para o uso e edição dos tilesets. Ambos sendo documentação da **Godot Docs**.
	- [Documentação Tilesets](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilesets.html)
	- [Documentação Tilemaps](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilemaps.html)
