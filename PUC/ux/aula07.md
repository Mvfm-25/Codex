### Atividade prática
- Organizar a turma em até 5 grupos
- Cada grupo recebe um conjunto de cartões
- Os grupos devem organizar os cartões recebidos em categorias com base em alguma tema/tópico
- **Temas/tópicos** são determinados pelo próprio grupo
- Ao final, cada grupo apresenta seus temas escolhidos.
- Atividade é especificamente sobre uma plataforma de e-commerce
- **Categorias**
	1. Pré-compra
	2. Especificação - Pesquisa
	3. Compra
	4. Confirmação - Parte financeira
	5. Pós-Compra
	6. Secção de Usuário -> **Determinado como tópico 0**
